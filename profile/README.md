# Grant Witness

[Grant Witness](https://grantwitness.org) is a watchdog group built to document changes in science grantmaking activity of the U.S. government. We track federal grant funding across several agencies, detailing disruptions to research grants in near real time. We aim to be comprehensive, authoritative, and fully transparent. We keep receipts, and we display every piece of data behind our results and conclusions.

We use this data to build and preserve a record of administration activities; to inform journalists, scientists, advocates, and other storytellers; and to support policymakers, Congress, and public interest legal groups seeking to protect American scientific leadership and innovation.

Our public GitHub organization contains data sets and open-source code used in our projects.

Grant Witness is a project of the [Raft Foundation](https://raft.foundation/), a 501(c)(3) nonprofit fiscal sponsor.
